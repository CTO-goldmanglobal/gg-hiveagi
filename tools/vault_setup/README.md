# Vault Setup

Automatically creates an Obsidian Vault directory structure that conforms to `specs/vault-structure-spec.md`.

## Usage

```bash
# Default path
python setup_vault.py

# Custom path
python setup_vault.py --target ~/HiveAGI
```

## What It Creates

```
<target>/
├── 00_Inbox/              # Raw Data staging
├── 01_Entries/            # Notes generated by the LLM Wiki
├── 02_Topics/             # MOC
│   ├── _MOC_Tourism.md
│   ├── _MOC_Industrial.md
│   └── _MOC_Legal.md
├── 03_SeedPackages/       # Output Seed Packages
├── 04_Templates/          # entry_template.md, schema_template.md
├── 99_Archive/            # Archive
├── _SCHEMA.md             # Structure documentation
└── _README.md             # Vault usage instructions
```

## Next Steps

1. Open this folder in Obsidian as a Vault
2. Place hardware-collected Raw Data (JSON) into `00_Inbox/`
3. (P1) Run the LLM Wiki Engine to generate notes in `01_Entries/`
4. Use `tools/seed_generator/generate_seed.py` to produce a Seed Package in `03_SeedPackages/`
