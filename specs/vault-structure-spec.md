# Obsidian Vault Structure Specification v1.0

## 1. Directory Structure

```
~/HiveAGI/                         # Vault Root
│
├── 00_Inbox/                      # Raw Data staging area
│   ├── 2026-07-25_1930_SydneyHarbour.json
│   └── 2026-07-25_1945_OperaHouse.json
│
├── 01_Entries/                    # Notes generated by the LLM Wiki
│   ├── 2026-07-25_Sydney_Harbour_Sunset.md
│   └── 2026-07-25_Opera_House_Night.md
│
├── 02_Topics/                     # MOC (Map of Content)
│   ├── _MOC_Tourism.md
│   ├── _MOC_Legal.md
│   └── _MOC_Industrial.md
│
├── 03_SeedPackages/               # Output Seed Packages
│   ├── seed_goldman_2026Q3_v1/
│   │   ├── manifest.json
│   │   └── entries/
│   └── seed_goldman_2026Q3_v1.md
│
├── 04_Templates/                  # Templates
│   ├── entry_template.md
│   └── schema_template.md
│
├── 99_Archive/                    # Archive of old notes
│
├── _SCHEMA.md                     # Core Schema document
└── _README.md                     # Vault usage instructions
```

---

## 2. Naming Conventions

| Type | Format | Example |
| :--- | :--- | :--- |
| Inbox JSON | `YYYY-MM-DD_HHMM_Location.json` | `2026-07-25_1930_SydneyHarbour.json` |
| Entry Markdown | `YYYY-MM-DD_Location_Subject.md` | `2026-07-25_Sydney_Harbour_Sunset.md` |
| MOC | `_MOC_Domain.md` | `_MOC_Tourism.md` |
| Seed Package Folder | `seed_contributor_YYYYMMDD_vX/` | `seed_goldman_20260725_v1/` |

---

## 3. Bidirectional Link Conventions

- Use the `[[Page Name]]` format
- Each entry should be associated with at least one MOC (e.g. `[[_MOC_Tourism]]`)
- Entries on the same topic should link to each other

---

## 4. Automated Workflow

| Stage | Action | Goal |
| :--- | :--- | :--- |
| 1 | Hardware trigger → JSON written to `/00_Inbox/` | Raw Data collection |
| 2 | LLM Wiki Engine reads `/00_Inbox/` | Convert into Markdown |
| 3 | Markdown written to `/01_Entries/` | Structured notes |
| 4 | MOC auto-updated | Link association |
| 5 | Seed Package Generator reads `/01_Entries/` | Output Seed Package |
| 6 | Seed Package written to `/03_SeedPackages/` | Ready for P2P exchange |
