# Footage Shot List — Legends of China Warriors

> One row per shot in the script. Each shot lists: what's in frame, the crop intent (V = vertical, L = landscape), and where to source it.
> **License rule:** every clip must be cleared for **commercial use**. Pexels/Pixabay = free commercial. Storyblocks/Artgrid = paid subscription commercial. ECH-shot = owned footage, PII-gated.

---

## Sourcing priority

1. **ECH-owned footage** — if ECH has shot these locations on past tours, use it first. Authentic, on-brand, no licensing cost. Run through the PII blur gate.
2. **Pexels / Pixabay** (free, commercial-clear) — search terms below. Quality varies; curate hard.
3. **Storyblocks / Artgrid** (paid) — for hero shots the free libraries can't deliver (Terracotta Warriors pit wide, Great Wall aerial).
4. **AI generation** (last resort, disclosed) — only for transition beats, never for hero shots of real landmarks. Customers can tell.
